# 📊 Sales Performance Report — Power BI

Interactive Power BI dashboard analyzing ₹55L+ in sales data — monthly trends, region-wise breakdown, product category analysis, and salesperson target achievement with conditional formatting.

# 🛠️ Skills Demonstrated
- DAX Measures (Total Revenue, Avg Order Value, MoM Growth %, Target Achievement %)
- KPI Cards, Line Chart, Bar Chart, Donut Chart, Gauge Chart
- Slicers for Region, Quarter, Month filtering
- Conditional formatting on Target Achievement %
- 3-page report layout with consistent theme

| Page | Visuals |
|---|---|

| Regional Analysis | Bar chart, Donut chart, Salesperson table |
| Target vs Actual | Clustered bar, Gauge chart, Conditional table |

---

# 🚀 How to Open
1. Download `Sales_Performance_Report.pbix` and `sales_data.csv`
2. Place both files in the same folder
3. Open `.pbix` in Power BI Desktop
4. If prompted, refresh data source path to point to `sales_data.csv`
